# Research Questions

## Asset pipeline

- What models and textures can be used legally and sustainably?
- How close can Three.js rendering get to in-game visual expectations without building a full Rust material clone?
- Which items require special handling for layering, emissive behavior, or unusual geometry?

## Data model

- What is the canonical slot taxonomy for Rust clothing and weapons?
- How should collections, artist names, colors, and tags be normalized?
- Which fields need to exist on day one to avoid painful migrations later?

## Pricing

- What are the practical rate limits and terms for Steam and Skinport access?
- How often should prices refresh?
- How should stale pricing be shown in the UI?

## Stealth Meter

- Which biome palettes should define each environment?
- Is palette similarity enough, or do contrast and silhouette matter too?
- How should the score be explained so users do not mistake it for a hard guarantee?

## Product strategy

- What is the single strongest reason a Rust player would bookmark GrubCheck?
- Is the first audience collectors, budget builders, or min-maxers?
- Which feature would still matter if community pages never took off?
