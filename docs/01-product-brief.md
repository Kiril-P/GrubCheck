# Product Brief

## Thesis

GrubCheck should help Rust players answer three questions fast:

1. Does this kit actually look good together?
2. Does it blend into the biome I care about?
3. Is there a cheaper way to build it right now?

If the product cannot answer those three questions credibly, the rest is noise.

## Core value proposition

High-trust 3D skin try-on for Rust with biome-aware evaluation and price awareness.

## Primary user types

- Players building themed kits.
- Budget-conscious buyers comparing marketplaces.
- Content creators showing off loadouts.
- Collectors browsing sets, artists, and coordinated fits.

## Product pillars

### 1. Visual trust

Users need to believe the preview is close enough to in-game reality to make spending decisions from it.

### 2. Fast discovery

Users should be able to move from one skin idea to a complete outfit without manually checking dozens of items.

### 3. Actionable utility

Stealth scoring, pricing, glow checks, and biome previews should help users make better choices, not just admire the render.

### 4. Shareable identity

Collections and community loadouts can become growth loops, but only after the preview engine is credible.

## Candidate feature buckets

### Rendering

- 3D mannequin
- item layering
- held weapon preview
- biome lighting
- emissive night mode

### Discovery

- collections
- artist search
- vibe tags
- color search

### Utility

- stealth meter
- price comparison
- ADS preview
- budget-based randomizer

### Growth

- community loadouts
- Twitch drop tracking

## Non-goals for v1

- trying to replicate the entire Rust cosmetic ecosystem at once
- building a fake social network before useful solo workflows exist
- shipping AI tagging before the metadata pipeline is stable
- building first-person and third-person rendering systems at the same time
