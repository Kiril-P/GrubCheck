# MVP Roadmap

## MVP definition

Launch a narrow GrubCheck that lets a user assemble a Rust outfit from a curated catalog, preview it on a mannequin in a few biome lighting presets, check a simple night mode, and compare cached marketplace prices.

That is enough to test demand. Anything beyond that should have to earn its way in.

## Phase 0: Validation

- confirm asset sourcing and usage rights
- confirm marketplace API access, rate limits, and caching rules
- define the item slot model and layering rules
- define what "good enough" visual fidelity means
- design the first version of the Stealth Meter as a documented heuristic

## Phase 1: Vertical slice

- one mannequin
- one static or lightly animated pose
- clothing layering for a limited slot set
- curated catalog of the most recognizable skins
- three biomes: forest, desert, arctic
- midnight glow check
- Steam and Skinport price snapshots with timestamps
- collection-based browsing

## Phase 2: Better discovery

- artist pages if source data supports them cleanly
- rules-based vibe tags
- color search
- saved loadouts
- random budget kit generator

## Phase 3: Expansion

- more item coverage
- more biomes
- community loadouts
- Twitch drop support
- held weapon preview

## Explicit cuts for the first build

- male and female character support at the same time
- full idle animation fidelity
- ADS / iron-sight preview
- wear / condition slider
- AI-generated tags as a dependency
- deep-sea biome as launch-critical scope

## Ship criteria

The MVP is ready when users can build a kit quickly, trust the preview, and learn something useful from biome and price context.

If any of those are missing, keep cutting.
